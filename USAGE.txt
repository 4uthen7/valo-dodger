====================================================
  Valo Dodger v6 - 使い方 (Windows)
====================================================

【v6 変更点】
  - サイド判定を確定 (Blue=守り / Red=攻め)
  - 「誰かが抜けた」と「試合開始」を正確に区別
  - ドッジペナルティ対応
    ・24h以内の自ドッジ回数を記録し警告
    ・--max-dodges-per-day で自ドッジを制限
    ・ドッジ後にキュー制限の残り時間を表示
  - 妨害用エージェントUUIDの誤りを修正

【ドッジペナルティの注意点（要約）】
  - 自分でドッジすると必ずペナルティ
    ・キュー制限: 初回は数分、連続で急増
    ・コンペ: 隠しRR減 4〜12（反復で増加）
    ・過度なAFK/ドッジで1日ランク制限→ゲーム禁止
    ・パッチ11.05以降、連続ドッジャーは急加速
  - 味方がドッジした場合: 自分はペナルティなし
    → sabotage モードが最も安全
  - エージェント未ロックの時間切れも「ドッジ」扱い
    → 放置せず combo モードを使うこと

【1】必要なもの
  - Windows PC（Valorantが動いているマシン）
  - Python 3.9+
    https://www.python.org/downloads/ からDL
    「Add Python to PATH」に必ずチェック

【2】起動
  Valorantを起動した状態でコマンドプロンプトを開く：

    cd C:\Users\ユーザー名\Desktop\valo

  【まずはコレ】動作確認（ドライラン + 詳細ログ）：
    python valo_dodger.py --dry-run --verbose

  【おすすめ】GUI（チート風コントロールパネル）：
    python valo_dodger.py --gui
    モード・送信間隔・仮ピック・妨害時間・ドッジ上限などを画面上で変更できます

  【本番】クリップボード送信（CLI・デフォルト）：
    python valo_dodger.py
    ※ 送りたい文章（例: dodge pls）をコピーしておくこと
      攻めスタート検出時、その文章をチャットに数秒おきに自動送信
    ※ 仮ピック（エージェント選択だけ回す）を有効にする場合:
       python valo_dodger.py --cycle-agents

  【本番】妨害（チャット+エージェント切替）：
    python valo_dodger.py --mode sabotage

  【本番】妨害→最終ドッジ：
    python valo_dodger.py --mode combo

  【本番】即ドッジ（⚠ ペナルティ・RR減）：
    python valo_dodger.py --mode dodge

  ダブルクリック起動：
    valo_dodger.bat をダブルクリック

【3】起動時にこう表示されればOK
  =======================================================
    Valo Dodger v6 (ペナルティ対応)
    GLZ:  https://glz-ap-1.jp.a.pvp.net
    ドッジ対象: Attack スタート
    モード: 妨害のみ
    24h内ドッジ: 0 / 2
  =======================================================

  そのままマッチング → エージェント選択に入ると
  「🎯 マッチ検出 | サイド: Attack」と表示される。
  Defense ならそのままプレイ、Attack なら指定モードで対処。

【4】サイド判定の確認方法
  - Blue=守り / Red=攻め で判定しています
  - 実際に「守りスタート」だったかゲーム内で確認して
    マッピングが合っているか確かめてください
  - --verbose でAPIレスポンスを確認できます

【5】403/1010 エラーが出た場合
  v6では定期的にトークンをリフレッシュするので
  基本的に出なくなるはず。
  それでも出る場合は --verbose でログを見て
  どのAPIでコケてるか確認してください。

【6】止め方
  Ctrl+C

【7】トラブルシューティング

   「lockfile が見つかりません」
     → Valorantを起動してから実行
     → Riot Clientをタスクバーから一旦終了→再起動

   「トークン取得失敗」
     → Riot Clientを再起動
     → lockfileのパスワードが変わってる可能性

   「GLZ base が null や unknown」
     → ShooterGame.logが無い/空
     → v6ではriot-geo APIに自動フォールバックするので
       普通は動くはず

   「サイド判定不可」
     → --verbose でAPIレスポンスを確認
     → TeamsフィールドやTeamIDの形式が
       パッチで変わった可能性

   「ドッジ失敗」
     → --verbose でHTTPステータス確認
     → ペナルティでドッジ制限中かも
     → valo_dodger_state.json の記録を確認

【8】モード一覧

   clip     = 攻め検出 → クリップボードの文章をチャットに
               数秒おきに送り続ける（エージェントは放置）
   dodge    = 攻め検出 → 即ドッジ
              ⚠ キュー制限 + コンペでは隠しRR減
   sabotage = 攻め検出 → チャット送信 + エージェント切替
               味方が抜けるのを待つ（自分にペナなし）
   combo    = 妨害 → 誰も抜けなければ最終ドッジ

【9】ペナルティ対策の推奨設定
  - 1日の自ドッジは最大2回までに抑える:
      --max-dodges-per-day 2
  - 基本は sabotage / combo を使う
  - 妨害中に時間切れになると「ドッジ」扱いになるので、
    --sabotage-duration はフェーズより短く（30秒前後）
【10】アカウントのペナルティ / キュー状態を見る (--status)
  Valorant起動中に以下を実行すると、ドッジせずに現在の状態を表示して終了します:

    python valo_dodger.py --status

  表示される内容:
  - キュー可否: 今すぐキューできるか / 制限中の残り時間
  - ランク / RR: 現在のランクとRR、直近のレーティング変動
  - 直近の競技アップデート: AFK/ペナルティが付いた試合の検出
  - アカウントのペナルティ一覧 (restrictions/v3/penalties)
  - 自ドッジ履歴: 24h以内 / 今日 / 累計
  - RR減リスクの目安（閾値は非公開のため目安表示）

  ※ 正確な「あと何回でRR減か」はRiotが公開しておらずAPIでも取れません。
    代わりに ①直近の競技アップデートのAFK/ペナルティ有無 ②自ドッジ履歴
     ③restrictions のペナルティ一覧 を組み合わせて判断します。
     2回目以降のドッジからRR減が始まる可能性が高いと言われています。

【11】GUIの使い方 (--gui)
  起動:
    python valo_dodger.py --gui
  （valo_dodger.bat をダブルクリックでも起動可）

  操作:
  1. 送りたい文章をコピーしておく（例: dodge pls）
  2. 左パネルでモードやオプションを設定
     - 実行モード: クリップボード送信 / 妨害 / 妨害→最終ドッジ / 即ドッジ
     - クリップボード送信: チャットへの自動送信のON/OFF
     - 仮ピックローテーション: エージェントを「選択」だけぐるぐる回す
       （ロックはしない。時間切れ=ドッジ扱いに注意）
     - 送信間隔 / 仮ピック間隔 / 妨害時間 / 24h自ドッジ上限
  3. 「▶ 起動」を押すと常駐開始
  4. 「⟳ ステータス取得」でキュー可否・ペナルティ・ドッジ履歴を確認
  5. 停止は「■ 停止」、終了は「⏹ 終了」

  ※ オプション変更は実行中でも反映されます（モード変更は次のマッチから）
  ※ コンソールを出したくない場合は bat 内の python を pythonw に変更
